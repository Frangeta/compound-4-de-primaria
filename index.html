🟢 Palabra simple

Es una sola palabra con significado: no se puede dividir en otras palabras.

sol · mesa · luna · libro

🔗 Palabra compuesta

Se forma uniendo dos o más palabras que ya existen y juntas significan algo nuevo.

saca+puntas = sacapuntas

tela+araña = telaraña

🛠️ ¿Cómo se forman?

Verbo + nombre: abre + latas = abrelatas

Nombre + nombre: boca + calle = bocacalle

Adjetivo + nombre: media + noche = medianoche

Adjetivo + adjetivo: agri + dulce = agridulce

💡 Truco: pregúntate: «¿puedo partirla en dos palabras que tengan sentido?». Si sí, es compuesta (para + guas no vale, pero para + aguas sí). Además, muchas compuestas no cambian en plural: un sacapuntas, dos sacapuntas.
